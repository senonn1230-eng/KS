最初の1回だけ｜クラウド設定

ここはあなた（最初に設定する管理者）だけが行います。ほかの管理者はこの作業は不要です。

1
設定コードをコピー下のボタンを1回押します。
2
Supabaseを開いて貼り付ける黒いSQL入力欄を長押し →「ペースト」→ 右上の「走る / Run」を押します。
3
Manager Proに戻って確認Runが終わったら、この画面に戻って下のボタンを押します。
Secret key / service_role key は使いません。設定コードの実行は最初の1回だけです。
スマホ版 Manager Pro 初回だけクラウド設定が必要な場合、画面の案内に沿って「設定コードをコピー → Supabaseを開く → 貼り付け → Run」を行います。
